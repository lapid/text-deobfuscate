# Code of conduct

*Written by the project's coding agent and revised on 2026-10-27 with the maintainer's direction
on offensive data. The maintainer may still replace it with the Contributor Covenant.*

We want a place where people can work on this project without being harassed or belittled.

## How we treat each other

- Be respectful. Disagree with the code, the data or the idea, not with the person.
- No harassment, insults, discrimination, or unwanted sexual attention.
- Do not publish other people's private information.
- Assume good faith, and say plainly when you are unsure.

## Offensive material in the data

Phishing, spam and prompt-injection text often contains profanity, insults and crude talk, and a
tool that must read such text has to be tested on it. So the evaluation sets keep real examples
of it. There is a difference between that and abuse:

- **Allowed as data:** real texts, with their source and licence, that contain profanity or
  crude language because that is how the real text is written. A sample may be added for the
  trick it shows, such as a disguised swear word, a masked insult in a phishing mail, or a
  rude injected instruction.
- **Not allowed, anywhere:** text we write ourselves to insult, threaten or demean a person or
  a group; material that sexualises children; threats or harassment aimed at a named private
  person; and other people's private information (home addresses, phone numbers, personal
  email addresses). Where a real text holds such details, mask them and say so in the commit.
- **Never as a joke or a test of limits.** Offensive samples are added because the tool needs
  them, not because they are offensive. Say in the pull request what the sample tests.
- **In discussion,** quote offensive text only as far as needed to explain a problem, and say
  that you are quoting data.

We do not use the project to build anything meant to deceive or harm people.

## Enforcement

The maintainer may remove comments, issues or pull requests that break these rules, and may ban
people who keep doing so. Report a problem to the maintainer through a private GitHub message
or, for a serious one, the repository's private reporting form.
